# THE ASHEN CROWN

**Current development target:** Unreal Engine 5.8 · source version 0.8.0  
**Legacy playable baseline:** Web/Three.js 0.7.1

THE ASHEN CROWN is an open-world fantasy RPG project about restoring a fallen capital and rebuilding a kingdom. This repository combines the Unreal Engine migration vertical slice with the retained browser-game source used as gameplay and content reference.

## Project layout

- `AshenCrown.uproject`, `Source/`, `Config/`, `Content/`, `Scripts/`, `Build/` — Unreal Engine 5.8 C++ project.
- `LegacyWebSource/` — preserved 0.7.1 browser game, server, content, launcher and automated tests.
- `Docs/` — Vietnamese porting matrix, production backlog, migration status and build report.
- `README_VI.md` — Unreal setup, controls, legacy-save import and Windows build instructions.

## Current Unreal slice

- 8 × 8 km procedural terrain blockout with 16 imported region records.
- Third-person movement and camera.
- Nine city districts with three restoration levels, adjacency unlocks, material costs and daily yields.
- Procedural placeholder buildings and scheduled citizen prototypes.
- SaveGame schema v2, legacy JSON importer, and guards that preserve unreadable or newer-version save slots.
- Original campaign data retained: factions, characters, recruitable heroes, hidden questlines and endings.

This is a source prototype, not a finished or packaged commercial game. The editor map is generated by `Scripts/Create_StartupMap.py` inside Unreal Editor.

## Quick start

1. Install Unreal Engine 5.8.x and the matching C++ toolchain.
2. Open `AshenCrown.uproject` and allow the editor to compile the C++ module.
3. In Unreal Editor, run `Scripts/Create_StartupMap.py` using **Tools → Execute Python Script**.
4. Restart the editor, open `/Game/Maps/AshenWorld`, then press Play.
5. See `README_VI.md` for controls, legacy-save import and Windows package scripts.

## Source validation

From the repository root:

```bash
python Scripts/validate_project.py
python -m py_compile Scripts/Create_StartupMap.py Scripts/validate_project.py
```

For the retained browser build:

```bash
cd LegacyWebSource
npm run check
npm test
```

Repository CI runs these source-level checks. They do **not** replace UnrealHeaderTool/MSVC compilation, Play-In-Editor testing, cooking or Windows packaging. No Unreal `.exe` is included or claimed as built.
